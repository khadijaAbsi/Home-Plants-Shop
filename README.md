# Home Plants Shop | Software Engineering Project

An academic software engineering project developed for **COMP433 – Software Engineering** at **Birzeit University** (2025–2026).

## Project Overview

Home Plants Shop is a proposed online platform for browsing, selecting, and purchasing home plants and related products. The project focuses on **requirements engineering, system analysis, UML modeling, and software architecture**, with workflows designed for customers and shop staff.

> **Project scope:** This repository presents the system's analysis and design documentation. The described features are part of the proposed system and should not be interpreted as a deployed application.

## Proposed Features

- Browse and search plant products, with details and care instructions.
- Manage a shopping cart, checkout, and payment options.
- Track order status and delivery progress.
- Request customer support through a chatbot, a support agent, or WhatsApp.
- Manage inventory and product information.
- Generate sales reports for shop managers.

## Software Engineering Work

The project report covers:

- Project planning, team coordination, and an Agile-oriented process.
- User and system requirements.
- Actor analysis, use-case specifications, and normal, alternative, and error scenarios.
- UML use-case, activity, sequence, and class diagrams.
- Component, overall architecture, and deployment diagrams.
- Design goals and system workflow analysis.
